## 핵심 역량

- **사용자 흐름·상태 설계:** 예약 단계의 종속 상태, URL 기반 검색 상태, 서버 상태와 클라이언트 상태 분리
- **API 연동·응답 데이터 검증:** REST API 연동, Zod 응답 검증·정규화, 로딩·빈 상태·오류 처리 및 재시도
- **테스트·품질 관리:** Vitest·Jest·React Testing Library·Playwright 및 GitHub Actions CI
